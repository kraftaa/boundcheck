## Explanations

**openai-agents, Chat Completions**

- `truncated-response` with streaming (UNKNOWN): In streaming mode the openai client raises APIConnectionError when the SSE stream is cut off and does not retry; the run ends before the result is re-sent. Non-streaming requests are retried and PASS.
- `mcp-protocol-error` (FAIL): Documented SDK default: default_tool_error_function returns a fixed message without the exception text; configurable with failure_error_function.
- `mixed-content` (UNKNOWN): Chat Completions tool results cannot carry images; the SDK drops the image block.
- `embedded-resource` (UNKNOWN): Not representable; the SDK serializes resource blocks as JSON inside the tool text.
- `resource-link` (UNKNOWN): Not representable; the SDK serializes the block as JSON inside the tool text.
- `audio-content` (UNKNOWN): Not representable; the SDK serializes the block as JSON inside the tool text.
